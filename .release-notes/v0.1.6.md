## TELOS SDK v0.1.6 — 2026-05-29

### Fixed

- **`telos init` now restarts the gateway when an installer registers a new upstream.** `telos init codex` (chatgpt mode) / `telos init openclaw` / `telos init hermes` inject new entries into `~/.telos/config.json`, but the gateway only reads `upstreams` at boot. If the daemon was already running, the previous idempotent `start_detached()` was a no-op, so requests to a freshly-added slug (e.g. `/upstreams/codex-chatgpt/responses`) kept 404ing with `unknown upstream slug` until the user manually ran `telos gateway restart`. `init/__main__.py` now detects that an installer mutated the telos config and calls `daemon.restart()` instead.
