## TELOS SDK v0.1.7 — 2026-05-31

### Added

- **`telos status`** — new CLI command. Shows gateway running state, per-harness install status, and live traffic summary in one place (`telos status --json` for machine-readable output).
- **`telos uninstall`** — new CLI command. Removes the proxy injection from the detected (or explicitly specified) harness and restores the original config.
- **`telos version` / `telos -V`** — prints the installed SDK version.

### Fixed

- **Gateway URL resolution in `telos status` and `telos uninstall`** — the commands now resolve the correct gateway URL even when the proxy runs on a non-default port or behind a custom `ANTHROPIC_BASE_URL`.
- **Claude TTL block** — `cache_control` blocks with `ttl: "1h"` were being emitted after `ttl: "ephemeral"` (5 m) blocks in some tool-heavy sessions, violating the Anthropic ordering requirement and triggering HTTP 400. Fixed by enforcing the `long-before-short` invariant in `AnthropicAdapter.plan_marks`.
- **Codex HTML passthrough guard** — Codex `/v1/responses` upstream now detects accidental HTML error responses from the backend (e.g. 403 Cloudflare pages) and converts them to a structured JSON error instead of forwarding raw HTML.
- **Uninstall / harness CLI hardening** — uninstall correctly handles partially-modified configs and external rewrites without data loss; CLI validates harness names and suggests the closest match on typo.

### Changed

- **Test suite overhaul** — 228 → 272 tests (all green). Added dedicated unit tests for `refpool` (slug-freeze invariants, `lint` fail-fast), bridge canonicalization determinism (the "byte-stable prefix" property), and Anthropic BP-trim priority (R7 / R2 mid-anchor). Removed 8 stale `EnvInstaller` tests, 3 cosmetic HTML-string assertions, and 3 true duplicates. Proxy/gateway monolithic async tests (previously invisible to pytest) split into individually collectable functions.
- **CI matrix** — pytest now runs on every push/PR across Python 3.10 / 3.11 / 3.12 / 3.13 (previously only 3.12 inside Docker). PyPI publish requires all four matrix legs to pass (`needs: [build, test]`).
