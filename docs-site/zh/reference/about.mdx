TELOS 由 [清华大学 LEAP Lab](https://www.leaplab.ai/) 构建——一个聚焦机器学习、多模态学习与具身智能的
研究团队。

## 立论

TELOS 只有一个主张：**上下文归你所有，agent 是雇来的。** `TelosIR` 是引擎无关、可序列化、可移植的上下文
表示——你的人设、你的工具、你的 20 轮会话线程，全部刻在同一块石碑上。今天交给 Claude，明天搬到
DeepSeek，今晚跑在本地 vLLM。

## 路线图

| 阶段 | 主旨 |
|---|---|
| **阶段 1** · 协议正确性加固 | 把"cache 不会被失效"从口号变成 CI 的红绿灯 |
| **阶段 2** · 生产可靠性与可观测性 | 让网关能安全地留在别人的生产流量上 |
| **阶段 3** · 接管调用链 | 从 prompt 改写器变成 agent 的流量平面 |
| **阶段 4** · 上下文成为资产 | 轨迹不再是日志——而是可 fork 的代码 |
