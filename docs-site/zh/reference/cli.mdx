```
telos                        裸命令：选择一个 harness 并进入其 CLI
telos <harness>              直接进入一个 harness（claude-code / codex / openclaw / hermes）
telos alias <harness>        设置裸 telos 默认进入的 harness
```

## `telos init`

```
telos init [options]
  --harness {claude-code,codex,openclaw,hermes,generic}
                       仅操作指定 harness（默认：自动探测全部）
  --gateway-url URL    网关地址（默认取自 ~/.telos/config.json）
  --status             只查看，不修改文件
  --no-gateway         只注入配置，不自动启动网关
```

无参数时，`telos init` 自动探测已安装的 harness CLI，向每个注入指向网关的配置，并在后台启动网关。

## `telos uninstall`

```
telos uninstall [options]
  --harness {claude-code,codex,openclaw,hermes,generic}
                       恢复单个 harness 的安装前状态
                       （默认：作用于所有已知 harness）
```

## `telos gateway`

```
telos gateway [start|stop|status|restart] [options]
  --host HOST          监听地址（默认 127.0.0.1）
  --port PORT          监听端口（默认 7171）
  --mode {none,telos,rtk,both}   默认优化档位
  --usage-log PATH     每次调用追加一行 jsonl
  --foreground         前台运行，阻塞（不后台化）
```

后台启动后，状态在 `~/.telos/gateway.json`，日志在 `~/.telos/gateway.log`。

## `telos mode`

```
telos mode [none|telos|rtk|both]   切换优化档位；热重载正在运行的网关并持久化
```

| 标签 | telos | rtk | 含义 |
|---|:---:|:---:|---|
| `none` | ✗ | ✗ | 纯透传 |
| `telos` | ✓ | ✗ | 仅 TELOS 前缀缓存（默认）|
| `rtk` | ✗ | ✓ | 仅 RTK 工具过滤 |
| `both` | ✓ | ✓ | 二者都开 |

## `telos dashboard`

```
telos dashboard [--static] [--no-open]   在浏览器中打开看板
telos dashboard --usage-log ~/.telos/usage.jsonl --out savings.html
```

网关运行则为实时，否则构建静态 HTML。

## `telos replay`

```
telos replay --list                                    列出已录会话
telos replay --session <id> --modes none telos rtk both
```

以 `max_tokens=1` 在每个模式下重放已录会话，只度量 prefill/缓存计费。见
[Replay 与对比](/zh/observability/replay)。

## `telos status` / `telos version`

```
telos status            一处查看网关状态 + 各 harness 安装 + 实时流量
telos status --json     机器可读输出
telos version           打印已安装 SDK 版本（别名：telos -V）
```

## `telos proxy`（隐藏别名）

```
telos proxy [options]   前台阻塞运行网关；与旧参数完全兼容
```

<Note>
  对 `telos gateway` / `telos init`，任何未传的 host/port/mode 取自 `~/.telos/config.json`；显式传入的值会
  被写回为新默认。
</Note>
